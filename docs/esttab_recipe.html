Exporting results with esttab: the full recipe

The short, runnable version lives in extensions/module_D_export_results.do. This page is the reference you come back to when writing your thesis.

One-time setup

esttab is part of the user-written estout package:

ssc install estout

If ssc install fails behind a university proxy, download from repec.sowi.unibe.ch/stata/estout and follow the manual installation note there.

The workflow: store, then tabulate

eststo clear
eststo m1: regress lhwage schooling
eststo m2: regress lhwage schooling female urban age c.age#c.age i.province
esttab m1 m2

eststo stores estimation results under a name; esttab prints any stored models side by side. That's the whole model.

To a file

You wantCommand
Wordesttab m1 m2 using "results/table.rtf", replace
LaTeXesttab m1 m2 using "results/table.tex", replace
Excel / CSVesttab m1 m2 using "results/table.csv", replace
Plain textesttab m1 m2 using "results/table.txt", replace

Use replace, and write into results/, which is kept out of version control.

The options that matter

esttab m1 m2 m3 using "results/table.tex", replace ///
    b(3) se(3)                          /// 3 decimals on betas and SEs
    star(* 0.10 ** 0.05 *** 0.01)       /// significance stars
    keep(schooling 1.cpoor#c.schooling) /// show only these coefficients
    order(schooling)                    /// coefficient order
    mtitles("Bivariate" "Controls" "Interaction") ///
    label                               /// use variable labels, not names
    r2 ar2                              /// R-squared and adjusted
    nonotes note("Robust SEs in parentheses.") ///
    title("Returns to schooling")

Other frequently needed pieces:

  • Robust / clustered SEs: put them in the regression, not in esttab: regress y x, vce(robust) or vce(cluster province). esttab reports whatever the stored model used.
  • Drop instead of keep: drop(*.province) hides fixed-effect blocks.
  • Wide tables: esttab, unstack or export to CSV and format in Excel.
  • Summary statistics table: estpost summarize + esttab, cells("mean sd min max").
