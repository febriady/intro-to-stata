# Intro to Stata: a classroom session and a self-study track

Materials for a short in-class introduction to Stata at the University of
Groningen, and a longer self-study track for anyone starting from zero.

The self-study track builds toward estimating a real research question: **what is the wage
return to a year of schooling, and is it the same for people who grew up poor?**
The exercise mirrors the research paper this session is drawn from:

> Febriady, A., A. Postepska & V. Angelini (2026), *"The Long Shadow: Childhood
> Poverty and the Returns to Education,"* [GLO Discussion Paper No. 1731](https://www.econstor.eu/bitstream/10419/338969/1/GLO-DP-1731.pdf).

**⚠️ All data in this repository are simulated.** No real Indonesia Family Life
Survey (IFLS) microdata are used or included anywhere; RAND's user agreement
prohibits redistribution. The synthetic dataset is generated by
[`code/simulate_data.do`](code/simulate_data.do) and only *mimics the structure*
of the paper's sample. You can regenerate it anytime by running that do-file
from the repo root (it re-creates `data/simulated/wage_survey_raw.dta`,
identically, thanks to a fixed random seed).

## Step 0: Get Stata itself

Students at the University of Groningen have two routes, and either is fine:

- **Run it without installing anything.** Log in to the University Workplace
  (**[uwp.rug.nl](https://uwp.rug.nl)**) in a browser and start Stata there. This is the
  quickest option, and the one to use if an install goes wrong.
- **Install it on your own laptop.** Download it from **IRIS**, the university's
  software portal, and use the licence details it gives you.

In the computer room, Stata is already installed; just log in and open it.

Use whichever version the university currently distributes; these materials do not
depend on having the newest one. Anything from **Stata 14 (2015) onwards** runs
everything here, and every version since has the commands this session teaches.

> If you are not at Groningen: any Stata 14+ installation works, including Small
> Stata. Nothing in this repository needs a specific flavour (IC / SE / MP).

### Step 2: Unzip it (really: this step fails the most)

Find the downloaded file (usually in your `Downloads` folder) and **extract**
it: right-click → *Extract All…* (Windows) or double-click (Mac).

> **Two traps here.** First: opening the ZIP and looking inside it is **not**
> the same as extracting it. If the address bar still shows `.zip`, Stata
> will not find the files. Second (Windows): *Extract All* usually creates a
> **folder inside a folder**: `intro-to-stata-main\intro-to-stata-main\`.
> The folder you want is the **inner** one: the one that directly contains
> `README.md` when you open it.

### Step 3: Tell the do-files where the folder is

Every do-file in this repository begins with a short block that sets the
working directory for you, keyed on your username. Open
`code/00_smoke_test.do` in the Do-file Editor and edit **one line**: replace
`YOUR-USERNAME` with what Stata prints when you type `display c(username)`,
and the path next to it with your unzipped folder. Do the same edit in each
do-file you run (it is the same block at the top of all of them). If you skip
this, the file stops at once and prints the three steps.

Alternatively, set the directory by hand for the current session only:
**File → Change Working Directory…** and select the unzipped folder, the one
that directly contains `README.md` (not `code/`, not the ZIP).

Equivalently, type in the Command window (adjust the path to yours, noting the
doubled folder name that Windows extraction typically produces):

```stata
cd "C:/Users/you/Downloads/intro-to-stata-main/intro-to-stata-main"
```


message tells you what to fix, or check the troubleshooting table below.

## Working through the session on your own

Run the files line by line, the way the classroom session runs its one do-file. Running a whole file at once makes all the teaching moments scroll
past in one burst.

1. Open a session file in Stata's **Do-file Editor**: *File → Open…* →
   `code/01_open_inspect.do`. (Do-files are just text files with Stata
   commands and comments; the comments are the narration.)
2. Read a comment block, then **select the command below it** and run the
   selection: **Ctrl+D** on Windows, **Cmd+Shift+D** on Mac (or the *Execute
   (do)* toolbar button). Watch the output, then move on.
3. Work through the files **in numeric order**. This matters: `02` and `03`
   create and extend the cleaned dataset that `04`, `05`, the exercises, and
   all extension modules need. If a later file complains about a missing
   variable, re-run `02` then `03`.

## Two ways through these materials

**The classroom session** lives in [`classroom/`](classroom/) and is what students
get in the room: a 105-minute session that builds one do-file from blank, task by
task, around an email from a supervisor asking for five numbers. It has its own
copy of the simulated data (a clean wage, ten mistyped ages), and it is
self-contained: nothing in it depends on the rest of this repository.

| File | What it is |
|---|---|
| `classroom/session.do` | The finished do-file, eleven tasks, with the reasoning in comments |
| `classroom/wage_survey.dta` | The classroom dataset, built by `classroom/make_classroom_data.do` |
| `classroom/exercise.html` | The tasks, with each answer folded away until clicked. Open it in a browser |
| `classroom/intro_stata_basics.pdf` | The slides (LaTeX source alongside) |

**The self-study track** is everything else: the five numbered do-files in `code/`,
run in order, then the exercises and the extension modules. It goes further than
the classroom session (cleaning, `egen`, the childhood-poverty interaction,
`predict`, exporting tables) and uses the original simulated data with its
planted wage errors. Its narration is in the do-files themselves, so it has no
slides of its own.

| # | Segment | Do-file |
|---|---|---|
| 1 | Setup: working directory, smoke test, **your first log file** | `00_smoke_test.do` |
| 2 | Opening and inspecting data: `use`, `describe`, `summarize`, `tabulate`, `browse`, graphs, `correlate` | `01_open_inspect.do` |
| 3 | Cleaning, and **how Stata thinks about missing values** | `02_cleaning_missings.do` |
| 4 | Generating variables: `gen`, `replace`, `egen`, labels | `03_generate_variables.do` |
| 5 | The Mincer regression, `predict`, and the childhood-poverty interaction | `04_mincer_regression.do` |

Exporting results with `esttab` lives in
[`extensions/module_D_export_results.do`](extensions/module_D_export_results.do) as
optional self-study. It is the one step that has to install a package, which can
fail on a locked-down university computer, and it reads better unhurried on the day
you actually need a table.

## Troubleshooting: the four most common beginner errors

| Symptom | Cause | Fix |
|---|---|---|
| `file ... not found  r(601)` right at the start | You are running from inside the ZIP, you never extracted it, **or you are in the outer folder of Windows' folder-in-a-folder extraction** | Extract the ZIP fully (Step 2), then in Step 3 pick the **inner** folder, the one directly containing `README.md` |
| `file data/simulated/... not found` but the file exists | Stata's working directory is not the repo root | **File → Change Working Directory** → select the folder containing `README.md` |
| `this is version XX file; you have version YY` or `r(9)` on the first line of a do-file | Your Stata is older than 14 (2015) | These materials require **Stata 14 or newer**; there is no workaround in this repo. Use a university computer-room installation or the campus license |
| Your `if` condition matches **too many** observations | **Stata stores missing (`.`) as the largest possible value**, so `if schooling > 12` silently includes every missing | Always write `if schooling > 12 & !missing(schooling)`. This is the session's designated "gotcha"; see segment 3 |

## A caveat on interpretation (read this!)

This session estimates returns to education **by OLS, for teaching purposes**.
The underlying paper shows that these OLS estimates are **biased by the
endogeneity of schooling**: people who obtain more schooling differ in
unobserved ways that also affect wages. The paper addresses this with a
control-function approach (Klein–Vella). In the paper, correcting for
endogeneity nearly doubles the poor/non-poor gap in returns. Curious how much
OLS misleads you here? That's exactly what optional
[Module C](extensions/module_C_endogeneity.do) shows. Because the data are
simulated, you can control for the normally-unobservable confounder and watch
the bias appear. For the real thing, read the paper:
[GLO DP No. 1731](https://www.econstor.eu/bitstream/10419/338969/1/GLO-DP-1731.pdf).

## A cheat sheet

Tim Essam and Laura Hughes' **Stata cheat sheets** are a one-page reference
per topic: data processing, transformation, analysis, plotting.

**[geocenter.github.io/StataTraining](https://geocenter.github.io/StataTraining/)**

They are © Essam & Hughes, released under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). We link to them rather
than copy them in, so you always get the current version. They were last revised in
2019, so a few newer commands are missing, but everything on them is still correct.
